## 内容质量

- [ ] **标题清晰准确** - 标题能够准确反映文档内容
- [ ] **概述完整** - 说明了文档目的和适用范围
- [ ] **内容准确** - 技术细节准确，与实际代码一致
- [ ] **内容完整** - 无明显遗漏，覆盖了所有必要的内容
- [ ] **示例可运行** - 代码示例经过验证，可以正常运行
- [ ] **图表清晰** - 图表（如有）清晰易懂，标注完整

## 格式规范

- [ ] **Frontmatter 完整** - 包含 name, description, status, owner, created 等字段
- [ ] **标题层级正确** - H1 → H2 → H3，层级清晰
- [ ] **链接有效** - 所有内部链接和外部链接都有效（无 404）
- [ ] **拼写正确** - 无拼写错误，特别是技术术语
- [ ] **语法正确** - 语句通顺，无语法错误
- [ ] **格式一致** - 与现有文档格式保持一致

## 技术准确性

- [ ] **技术细节准确** - 配置、API、参数等准确无误
- [ ] **与架构一致** - 与现有架构设计不冲突
- [ ] **配置已验证** - 配置示例经过实际验证
- [ ] **截图最新** - 截图（如有）反映最新 UI

## 文档状态

- [ ] **状态标记正确** - draft | in_review | approved
- [ ] **审核人指定** - 至少 1 人审核（必须包含 Tech Lead）
- [ ] **复审周期设置** - 与 Release 周期同步
