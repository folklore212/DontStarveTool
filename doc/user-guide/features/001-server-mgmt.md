# 服务器详情页设计

## 页面结构

ServerDetailPage 重写为四个功能完善的标签页。每个标签页通过 Node Gateway 与目标服务器通信。

```
┌──────────────────────────────────────────────────┐
│  ← 返回    服务器名称 (online/offline)             │
│  host:port  系统: Ubuntu 22.04  运行: 3天          │
├──────────────────────────────────────────────────┤
│  [控制台] [玩家] [模组] [存档] [定时任务] [设置]    │
├──────────────────────────────────────────────────┤
│                                                  │
│              标签页内容区域                        │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 控制台标签页

```
┌──────────────────────────────────────────────────┐
│  服务器: MyWorld                                  │
│  ┌─ 状态栏 ─────────────────────────────────────┐ │
│  │ 🟢 Master 运行中 (PID 12345)  Caves 运行中    │ │
│  │ 玩家: 3  天数: 45  季节: 秋                  │ │
│  └──────────────────────────────────────────────┘ │
│                                                  │
│  ┌─ Shard 选择 ─────────────────────────────────┐ │
│  │ [Master ▾] [Caves]                           │ │
│  └──────────────────────────────────────────────┘ │
│                                                  │
│  ┌─ 日志输出 (自动滚动) ────────────────────────┐ │
│  │ [00:01:02] [INFO] World loaded               │ │
│  │ [00:01:05] [INFO] Player Wilson joined       │ │
│  │ [00:02:10] [WARN] Entity limit approaching   │ │
│  │ ...                                          │ │
│  └──────────────────────────────────────────────┘ │
│                                                  │
│  ┌─ 命令输入 ───────────────────────────────────┐ │
│  │ > c_announce("hello")              [发送]     │ │
│  └──────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

**交互细节**：
- 打开标签页 → HTTP 请求最近 100 行日志（首次加载快）
- 然后 WebSocket 订阅实时日志（`dst.logs.subscribe`）
- WebSocket 断开时自动降级为 HTTP 轮询（5 秒间隔）
- 连接恢复后自动切回 WebSocket
- 命令历史通过 ↑↓ 方向键浏览
- 日志支持过滤（搜索关键字、按级别 ERROR/WARN 高亮）
- ANSI 颜色代码渲染为实际颜色

## 玩家标签页

```
┌──────────────────────────────────────────────────┐
│  [刷新] [踢出选中] [封禁] [导出]                   │
├──────────────────────────────────────────────────┤
│  在线: 3 | 管理员: 2 | 黑名单: 5                   │
├──────┬──────────┬─────────┬───────┬──────────────┤
│ 玩家  │ 角色      │ 时长    │ Ping  │ 操作         │
├──────┼──────────┼─────────┼───────┼──────────────┤
│ Wilson│ Wilson   │ 2h 30m  │ 45ms  │ [踢出][封禁]  │
│ Willow│ Willow   │ 1h 15m  │ 60ms  │ [踢出][封禁]  │
│ WX-78 │ WX-78    │ 15m     │ 80ms  │ [踢出][封禁]  │
└──────┴──────────┴─────────┴───────┴──────────────┘

┌─ 管理员列表 ──────────────────────────────────────┐
│  steam_id              │ 添加时间     │ 操作       │
│  KU_xxx1               │ 2026-01-01  │ [移除]      │
│  [+添加管理员]                                    │
└──────────────────────────────────────────────────┘

┌─ 黑名单 ──────────────────────────────────────────┐
│  steam_id              │ 原因         │ 操作       │
│  KU_xxx2               │ Griefing     │ [解封]      │
└──────────────────────────────────────────────────┘
```

**交互细节**：
- 手动刷新按钮 → `dst.players.list`
- 公开 REST 接口 `GET /api/v1/servers/{id}/players` 给其他模块调用
- Kick/Ban 需要二次确认弹窗
- Ban 支持填写原因备注

## 存档标签页

```
┌──────────────────────────────────────────────────┐
│  [新建备份] [恢复选中] [下载]                       │
├──────┬──────────┬────────┬──────────┬────────────┤
│ 名称  │ 大小      │ 时间    │ 备注      │ 操作       │
├──────┼──────────┼────────┼──────────┼────────────┤
│ auto1│ 45 MB    │ 05-15  │ 自动备份  │ [恢复][下载] │
│ pre  │ 42 MB    │ 05-14  │ 更新前    │ [恢复][下载] │
│ day1 │ 38 MB    │ 05-01  │ 开服首日  │ [恢复][下载] │
└──────┴──────────┴────────┴──────────┴────────────┘

┌─ 自动备份设置 ────────────────────────────────────┐
│  ☑ 启用自动备份                                   │
│  Cron: [0 4 * * *        ▾] (预设: 每天4点)       │
│  保留天数: [7]                                     │
│  [保存设置]                                        │
└──────────────────────────────────────────────────┘
```

**交互细节**：
- 备份存储到管理平台，不占服务器磁盘
- 备份列表显示平台中的所有备份（已从服务器同步的）
- 恢复时从平台下载到服务器 → 解压 → 提示重启
- 自动清理超期备份
