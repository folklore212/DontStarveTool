# 仪表盘设计

## 概述

全局服务器状态概览 + 系统资源监控 + 告警中心。

## 数据来源

- 概览卡片：平台数据库聚合查询
- 服务器列表：STOMP `/topic/servers/status` 实时推送
- 资源图表：内存环形缓冲区（最后 24 小时数据点），后续升级 TimescaleDB
- 告警历史：`audit_logs` 表（类型 = alert）
- 玩家趋势：Node 每 5 分钟推送 `event.metrics` 包含 player_count

## 指标卡片

每个服务器卡片点击进入 ServerDetailPage。卡片悬停显示更多信息（运行时长、DST 版本、最后备份时间）。
