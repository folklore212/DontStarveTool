# 地图预览设计

## 概述

在 Web 面板上实时查看 DST 服务器地图。Node 读取地图二进制数据，解析为瓦片后推送。前端 Canvas 渲染，叠加资源图标和玩家位置。

## 数据流

```
DST 服务器 save/session/xxx/
  └─ Node 读取地图二进制文件
     └─ 解析为瓦片数组 (tile_type, x, y)
        └─ WebSocket 推送到平台
           └─ 前端 Canvas 渲染
```

## 渲染层

| 海洋 | #1a5276 |
| 浅海 | #2980b9 |

| 森林 | #1e8449 |

| 岩石地 | #7f8c8d |
| 沼泽 | #2c3e50 |
| 草原 | #f1c40f |

### 叠加层1：资源图标
- 矿石 (🪨)、树木 (🌲)、浆果丛 (🫐)、胡萝卜 (🥕)、草 (🌿)、树枝 (🌱)
- 蜘蛛巢 (🕷️)、猪屋 (🐷)、牛群 (🐮)、兔洞 (🐰)
- 虫洞入口/出口配对

### 叠加层2：生物群落边界
- 不同颜色半透明覆盖标识群落范围

### 叠加层3：实时位置
- 玩家位置 (蓝点，带名称标签)
- 可切换显示/隐藏

## 交互

- 鼠标滚轮缩放
- 拖拽平移
- 双击放大到点击位置
- 图例切换（资源/生物群落/玩家）
- "适应窗口"按钮

## 性能

- 大世界地图瓦片数据较多（默认世界约 200KB 压缩数据）
- Node 首次推送全量数据，后续仅推送变化的瓦片（资源被采集）
- Canvas 只渲染可视区域内的瓦片（虚拟滚动）
- 缩放级别低时合并瓦片（降低渲染密度）

## 技术选型

- 渲染引擎：Canvas 2D API（轻量、高性能）
- 不引入游戏引擎（Phaser/PixiJS），减少依赖
