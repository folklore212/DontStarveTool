# 部署第一个服务器

本教程将带你从零开始，在 **15 分钟内** 部署第一个 DST 服务器。

## 前置条件

- ✅ 已完成 [5 分钟快速体验](../../getting-started/001-quickstart.md)
- ✅ 平台已启动并可访问
- ✅ 已创建管理员账号

---

## 步骤 1: 创建服务器模板

### 1.1 登录管理后台

```
URL: http://localhost:3000
用户名：admin
密码：（查看 .env 文件）
```

### 1.2 导航到模板管理

```
左侧菜单 → 模板管理 → 创建模板
```

### 1.3 填写模板信息

**基本信息**:
```
模板名称：我的第一个服务器
模板描述：新手教学服务器
世界预设：默认预设
最大玩家数：10
PVP：关闭
```

**世界设置**:
```
季节：秋季开局
白天长度：标准
资源丰富度：默认
生物数量：默认
```

**模组配置**（可选）:
```
✓ 显示伤害
✓ 几何放置
✓ 额外 mod 槽位
```

### 1.4 保存模板

点击 **保存** 按钮，等待模板创建成功提示。

---

## 步骤 2: 部署服务器

### 2.1 导航到部署向导

```
左侧菜单 → 服务器管理 → 部署向导
```

### 2.2 选择模板

从下拉列表中选择刚创建的模板：
```
选择模板：我的第一个服务器
```

### 2.3 配置服务器

**服务器信息**:
```
服务器名称：新手教学服
服务器密码：123456（可选）
服务器描述：欢迎新手玩家
```

**集群配置**:
```
集群名称：新手教学集群
分片数量：1（主世界）
洞穴：暂不开启
```

**目标机器**:
```
选择已注册的 Node Agent
或选择本地部署（需要 SSH 配置）
```

### 2.4 开始部署

点击 **部署** 按钮，进入部署流程。

**部署进度**:
```
[1/5] 创建服务器记录... ✓
[2/5] 生成世界配置... ✓
[3/5] 下载模组... ⏳
[4/5] 启动 DST 进程... ⏳
[5/5] 验证运行状态... ⏳
```

### 3.1 查看服务器状态

部署完成后，自动跳转到服务器详情页。

**状态检查**:
```
服务器状态：🟢 运行中
玩家数量：0/10
运行时间：00:00:00
世界天数：Day 1
```

### 3.2 查看服务器日志

```
左侧菜单 → 服务器管理 → 服务器列表 → 新手教学服 → 日志
```

**预期日志**:
```
[INFO] Server started successfully
[INFO] Listening on port 10999
[INFO] Steam query port: 27016
[INFO] Master server communication established
```

### 3.3 测试连接

**在游戏内连接**:
1. 打开 DST 游戏
2. 点击 **在线游戏**
3. 点击 **服务器** 标签
4. 查找 "新手教学服"
5. 输入密码 `123456`
6. 点击 **连接**

## 常见问题

### Q1: 部署失败

**错误**: "Node Agent 未响应"

**解决方案**:
```bash
# 1. 检查 Node Agent 状态
systemctl status dst-node-agent

# 2. 查看 Node Agent 日志
journalctl -u dst-node-agent -f

# 3. 重启 Node Agent
sudo systemctl restart dst-node-agent
```

### Q2: 服务器无法连接

**错误**: "无法连接到服务器"

**检查清单**:
```
□ 服务器状态是否为"运行中"
□ 端口是否开放（10999, 27016）
□ 防火墙是否阻止
□ 密码是否正确
```

**解决方案**:
```bash
# 检查端口
netstat -tlnp | grep 10999

# 开放端口（Ubuntu）
sudo ufw allow 10999/tcp
sudo ufw allow 27016/udp
```

### Q3: 模组下载失败

**错误**: "Workshop 下载超时"

**解决方案**:
```bash
# 1. 检查 Steam 连接
steamcmd +login anonymous +quit

# 2. 清理模组缓存
rm -rf /opt/dst-server/mods/*

# 3. 重新部署
# 在平台中点击"重新部署"
```

### Q4: 世界生成失败

**错误**: "世界生成超时"

**解决方案**:
```bash
# 1. 查看世界生成日志
tail -f /opt/dst-server/MyDediServer/Log.txt

# 2. 检查磁盘空间
df -h

# 3. 重新生成世界
# 在平台中点击"重置世界"
```

## 快速参考卡

### 服务器状态说明

| 状态 | 图标 | 说明 |
|------|------|------|
| 运行中 | 🟢 | 服务器正常运行 |
| 启动中 | 🟡 | 正在启动进程 |
| 停止中 | 🟠 | 正在停止进程 |
| 已停止 | 🔴 | 服务器已停止 |
| 错误 | ⚫ | 发生错误，查看日志 |

### 常用端口

| 端口 | 协议 | 用途 |
|------|------|------|
| 10999 | UDP | 游戏服务器 |
| 27016 | UDP | Steam 查询 |
| 10998 | TCP | 服务器通信 |

### 常用控制台命令

```lua
-- 玩家管理
c_spawn("prefab", count)      -- 生成物品
c_give("prefab")              -- 给物品
c_kill()                      -- 杀死玩家

-- 世界管理
c_setseason("autumn")         -- 设置季节
c_startwinter()               -- 开始冬天
c_regenerateworld()           -- 重生世界

-- 服务器管理
c_shutdown()                  -- 关闭服务器
c_restart()                   -- 重启服务器
c_rollback(days)              -- 回档
```
